Off the clock, I'm playing guitar or working through my game backlog.

Tools

Design

Figma This is what I use the most for wireframing and prototyping — I've even made icons with this. Don't do that.
Ps Photoshop I used to use it for everything at some point — web layouts, prints, you name it. These days it mostly comes out for quick touch-ups.
Ai Illustrator I use this mainly for prints and icons. It doesn't come up as often anymore, but it's still my first pick for vector work when it does.
Ae After Effects I've made several animated presentations, walkthroughs, and brought interactive designs to life before Figma was around. I still enjoy working with Ae, most of the time.
DaVinci Resolve My go-to tool for editing, color grading, or converting videos to a different format, size, or framerate.
Blender The only 3D software I've picked up. Not aiming to be a 3D artist — I use it to build simple, usable renders for items or any UI element that "needs" 3D.

Game Engines

Unreal Engine 5 I bring what I've made in Figma here and prepare the layouts so technical designers can hook them up. I can read UI widget blueprints and materials well enough to speak the same language as the engineers who take it from there.
GameMaker I made my first arcade game with this. I like this one.

AI

Claude The AI assistant I use the most — it helped me code the game I made, and it made this site too. ¡Gracias, Claudio!
Gemini Mainly for brainstorming, quick images, or daily use — not so much for long-term projects.
